## Introduction

In this tutorial, you'll learn how to rank ERC20 tokens by market cap using the Moralis API. You can also sort by trading volume and liquidity. This is useful for building token discovery platforms, market dashboards, or trading screeners. We'll use the following Moralis API endpoint:

- [Token Search](/data-api/universal/token/search/token-search) - Search and rank tokens by market cap, volume, or liquidity

<Note>
  Token Search requires a `query`, so it ranks the tokens matching your search rather than the entire token universe. There is no endpoint that returns a global top N by market cap. If that's what you need, [reach out to the team](https://admin.moralis.com/) (via chat widget).
</Note>

## Prerequisites

- Node.js v18+ installed
- A Moralis API key ([get one](https://admin.moralis.com))

## Step 1: Set Up Your Project

Create a new directory for your project and initialize it:

```bash
mkdir get-top-tokens && cd get-top-tokens
npm init -y
```

## Step 2: Create the Script

Create a file called `index.js` and add the following code:

```javascript
// index.js
const API_KEY = 'YOUR_API_KEY';

async function getTopTokens() {
  const params = new URLSearchParams({
    query: 'pepe',
    chains: 'eth',
    sortBy: 'marketCapDesc',
    limit: '20',
  });

  const response = await fetch(
    `https://deep-index.moralis.io/api/v2.2/tokens/search?${params}`,
    {
      headers: {
        accept: 'application/json',
        'X-API-Key': API_KEY,
      },
    }
  );

  const data = await response.json();
  console.log(JSON.stringify(data, null, 2));
}

getTopTokens();
```

Replace `YOUR_API_KEY` with your actual Moralis API key.

## Step 3: Run the Script

Execute the script to get tokens ranked by market cap:

```bash
node index.js
```

## Query Parameters

| Parameter | Description |
|-----------|-------------|
| `query` | Required. Contract address, pair address, token name, or symbol to search for |
| `chains` | Comma-separated chains to filter by. Omit for a cross-chain search |
| `sortBy` | `marketCapDesc`, `liquidityDesc`, `volume24hDesc`, or `volume1hDesc` |
| `limit` | Page size of the result |
| `isVerifiedContract` | Set to `true` to return only verified contracts |

## Understanding the Response

| Field | Description |
|-------|-------------|
| `tokenAddress` | Token contract address |
| `chainId` | Chain the token is on, in hex |
| `name` / `symbol` | Token name and symbol |
| `usdPrice` | Current price in USD |
| `marketCap` | Current market capitalization in USD |
| `fullyDilutedValuation` | FDV based on total supply |
| `usdPricePercentChange` | Price change over one hour and one day |
| `volumeUsd` | Trading volume over one hour and one day |
| `totalLiquidityUsd` | Total liquidity across pairs, in USD |
| `totalHolders` | Number of unique holders |
| `securityScore` | Token security score (0-100) |
| `isVerifiedContract` | Whether the contract is verified |
