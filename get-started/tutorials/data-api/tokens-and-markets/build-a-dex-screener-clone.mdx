## Introduction

In this tutorial, you'll learn how to build a DEX token screener similar to DexScreener using the Moralis API. The screener will display tokens ranked by volume with real-time prices, market cap, and price changes. We'll use the following Moralis API endpoint:

- [Token Search](/data-api/universal/token/search/token-search) - Search and rank tokens by volume, market cap, or liquidity

<Note>
  Token Search requires a `query`, so it ranks the tokens matching your search rather than the entire token universe.
</Note>

## Prerequisites

- Node.js v18+ installed
- A Moralis API key ([get one](https://admin.moralis.com))

## Step 1: Set Up Your Project

Create a new directory for your project and initialize it:

```bash
mkdir dex-screener && cd dex-screener
npm init -y
```

## Step 2: Create the Script

Create a file called `index.js` and add the following code:

```javascript
// index.js
const API_KEY = 'YOUR_API_KEY';

async function getTopTokens() {
  const params = new URLSearchParams({
    query: 'pepe',
    chains: 'eth',
    sortBy: 'volume24hDesc',
    isVerifiedContract: 'true',
    limit: '20',
  });

  const response = await fetch(
    `https://deep-index.moralis.io/api/v2.2/tokens/search?${params}`,
    {
      headers: {
        accept: 'application/json',
        'X-API-Key': API_KEY,
      },
    }
  );

  const data = await response.json();
  console.log(JSON.stringify(data, null, 2));
}

getTopTokens();
```

Replace `YOUR_API_KEY` with your actual Moralis API key.

## Step 3: Run the Script

Execute the script to get the top tokens:

```bash
node index.js
```

## Understanding the Response

| Field | Description |
|-------|-------------|
| `tokenAddress` | Contract address of the token |
| `chainId` | Chain the token is on, in hex |
| `name` | Token name |
| `symbol` | Token ticker symbol |
| `logo` | URL to token logo image |
| `usdPrice` | Current price in USD |
| `marketCap` | Total market capitalization in USD |
| `fullyDilutedValuation` | FDV based on total supply |
| `usdPricePercentChange.oneDay` | 24-hour price change percentage |
| `volumeUsd.oneDay` | 24-hour trading volume in USD |
| `totalLiquidityUsd` | Total liquidity across pairs, in USD |
| `totalHolders` | Number of token holders |
| `securityScore` | Token security score (0-100) |
| `isVerifiedContract` | Whether the contract is verified |
