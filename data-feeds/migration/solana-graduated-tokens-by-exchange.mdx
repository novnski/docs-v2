Moralis **Data Feeds** give you the complete, decoded onchain dataset, including the moment a Solana launchpad
token completes its bonding curve and **migrates to a DEX pool**, as a real-time stream you own. This guide moves
your `/token/:network/exchange/:exchange/graduated` integration onto Data Feeds, so you track graduations straight
from that data lake, with **no per-call limits**.

```
GET /token/:network/exchange/:exchange/graduated
```

This is a direct migration and a sibling of [New tokens by exchange](/data-feeds/migration/solana-new-tokens-by-exchange):
the same [`tokenBondingStatus`](/data-feeds/recipes/token/token-bonding-status) recipe carries the launchpad events,
and **graduation is the `migrated` event**, the point a token leaves the bonding curve for a real DEX pool.

## How Data Feeds works

Data Feeds is a single service over one data lake of decoded onchain data, consume the **same data** however fits
your stack: stream it with your existing **Kafka / AMQP / SQS** clients (or **REST / Arrow Flight**), **land it
with the sink** into your own database, or **query it from your warehouse** via Iceberg. See
[What are Data Feeds?](/data-feeds/concepts/what-are-data-feeds) for the full picture. For a ranked, on-demand list the
**sink** is the smoothest path, so we'll use it here.

## What to expect

You're moving from a pre-packaged response to the **underlying data that produces it**, see
[Data Feeds vs. the legacy API](/data-feeds/concepts/data-feeds-vs-the-legacy-api). Applied to graduated tokens:

**Comes through exactly**
- **The token** (`tokenAddress`) and **when it graduated** (`graduatedAt`), from its `migrated` launchpad event on
  the chain.
- **The launchpad**, and the token's **name** and **symbol**.

**Calculated for you, from real trades**
- **Prices**, **liquidity**, and **FDV** aren't fields in the launchpad feed. After graduation the token trades on
  a normal DEX pool, so price it with [Token Prices](/data-feeds/recipes/token/token-prices) and
  [Pair Reserves](/data-feeds/recipes/markets/pair-reserves) like any DEX token, or omit them.

**Yours to control**
- **What counts as "graduated."** It's the set of tokens with a `migrated` event on the launchpad you pick,
  ordered by graduation time, your list, your rule.

**Add the extras you want**
- `logo` is off-chain, so it's not in the feed, bring your own token list or omit it.

**Good to know**
- **Graduation is a single, decisive event.** `migrated` means the bonding curve completed and the token moved to
  a DEX, so the presence of that event is the signal, no separate flag to interpret.

## Build it with the sink (recommended)

### Step 1: Turn on the recipe

| What you need | Recipe | Table it keeps up to date |
|---|---|---|
| Launchpad events incl. migrations | `tokenBondingStatus` | `fact_launchpad_events` (ClickHouse); `launchpad_events` (Postgres, MySQL) |
| Token decimals (authoritative), optional | `tokenMetadata` | `token_metadata` |

### Step 2: Bring it together in one view

"Graduated" tokens are those with a `migrated` event, newest graduation first:

```sql
CREATE VIEW graduated_tokens_by_exchange AS
SELECT
  token_address,
  exchange_address,
  minIf(event_ts, event_type = 'migrated') AS graduated_at,
  anyLast(pool_address)                    AS pool_address   -- empty on the Solana feed today; see note below
FROM recipe_token_bonding_status.fact_launchpad_events FINAL
GROUP BY token_address, exchange_address
HAVING maxIf(1, event_type = 'migrated') = 1;  -- has graduated
-- query it per launchpad: WHERE exchange_address = :exchange ORDER BY graduated_at DESC
```

`graduatedAt` maps to `graduated_at` (the migration time). `pool_address` is **empty on the Solana feed today**, so
drop it or resolve the pool from your own source. Price post-graduation tokens with
[Token Prices](/data-feeds/recipes/token/token-prices) once they're trading on a DEX pool (calculated, as noted in
[What to expect](#what-to-expect)).

### Step 3: Query it from your app

```ts
import { createClient } from '@clickhouse/client';

const ch = createClient({ url: process.env.CLICKHOUSE_URL });
const PUMPFUN = '6EF8rrecthR5Dkzon8Nwu78hRvfCKubJ14M5uBEwF6P';

async function getGraduatedTokens(exchange = PUMPFUN, limit = 50, before?: string) {
  const { rows } = await ch.query({
    query: `
      SELECT token_address, graduated_at, pool_address
      FROM graduated_tokens_by_exchange
      WHERE exchange_address = {exchange:String}
        ${before ? 'AND graduated_at < {before:DateTime64}' : ''}
      ORDER BY graduated_at DESC
      LIMIT {limit:UInt32}`,
    query_params: { exchange, limit, before },
    format: 'JSONEachRow',
  }).then((r) => r.json());
  return rows;
}
```

You're now tracking graduations live, the moment each token migrates off the bonding curve.

### Step 4: Add the extras you want

`logo` is off-chain, skip it, bring your own Solana token list, or layer one in.

## Other ways to consume this data

The **same feed** is available however you build, all reading the one data lake:

- **Your existing message clients.** Point **Kafka**, **AMQP / RabbitMQ**, or **Amazon SQS** at Data Feeds and
  react to graduations the moment they happen.
- **REST / Arrow Flight.** Read the decoded block stream directly (Solana, namespace `solana-mainnet`, topic
  `master-3`):
  ```
  GET /api/v1/continuum/{namespace}/{topic}            # records by position range
  GET /api/v1/continuum/{namespace}/{topic}/schema     # the topic's Arrow schema
  ```
  Each record carries the decoded `launchpadEvents` array (including `migrated`) the recipe projects from.
- **Your warehouse / notebook.** Every feed is an Iceberg table, query from Snowflake, BigQuery, Spark, DuckDB,
  dbt without moving data.

## Field mapping reference

| `/token/:network/exchange/:exchange/graduated` | Data Feeds | Fidelity |
|---|---|---|
| `tokenAddress` | `token_address` | exact |
| `graduatedAt` | `minIf(event_ts, event_type='migrated')` | exact |
| `name`, `symbol` | `fact_launchpad_events` / `token_metadata` | exact |
| `decimals` | `token_metadata.decimals` | exact |
| `priceUsd`, `priceNative` | [Token Prices](/data-feeds/recipes/token/token-prices) once on a DEX pool (post-graduation) | calculated |
| `liquidity` | [Pair Reserves](/data-feeds/recipes/markets/pair-reserves) × price | calculated |
| `fullyDilutedValuation` | `token_metadata.total_supply` × price | calculated |
| `logo` | add yourself | off-chain |
| `poolAddress` | not populated on the Solana feed today — resolve from your own source | add yourself |

## Good to know

- **Graduation = `migrated`.** Presence of that event is the signal; `graduated_at` is the migration time.
- **Post-graduation pricing** comes from the token's normal DEX pool (Token Prices / Pair Reserves) once it's
  trading there. Note `pool_address` is empty on the Solana feed today.
- **You pick the launchpad** via `exchange_address` (the old `:exchange`) or `launchpad_platform`.
- **No per-call limit**; page with a keyset on `graduated_at`.
