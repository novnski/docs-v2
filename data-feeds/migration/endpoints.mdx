This is the full list of Moralis REST endpoints covered by a migration guide, **ordered by how widely each is
used** (most-used first). Find the one you call today and open its guide — each one answers the same question:
what happens to your exact response, field by field.

New to Data Feeds first? Read the [migration overview](/data-feeds/migration/overview) for how the API and
Data Feeds differ, then come back here to pick your endpoint.

<Note>
One endpoint often maps to **more than one recipe**. The "Headline fidelity" column tells you what to expect:
**exact** comes straight from the chain, **calculated** is derived from live onchain activity (best compared
with a small tolerance), and **add yourself** is an off-chain signal you bring or drop.
</Note>

## Solana endpoints

The sunsetting Solana **token-holder** endpoints map onto the same holder recipes, pointed at Solana (the feed's
SPL `tokenTransfers` carry absolute post-balances, so the recipes run unchanged):

| Legacy endpoint | Guide | Headline fidelity |
|---|---|---|
| `GET /token/:network/:address/top-holders` | [Solana top token holders](/data-feeds/migration/solana-top-holders) | exact, USD calculated |
| `GET /token/:network/holders/:address` | [Solana token holder metrics](/data-feeds/migration/solana-token-holders) | totalHolders exact, tiers your-definition |
| `GET /token/:network/holders/:address/historical` | [Solana historical token holders](/data-feeds/migration/solana-historical-holders) | per-bucket totals exact, change calculated |

The sunsetting **launchpad / discovery** endpoints (pump.fun, Raydium LaunchLab) are all served by the one
[`tokenBondingStatus`](/data-feeds/recipes/token/token-bonding-status) recipe over the `launchpadEvents` feed:

| Legacy endpoint | Guide | Headline fidelity |
|---|---|---|
| `GET /token/:network/exchange/:exchange/new` | [New tokens by exchange](/data-feeds/migration/solana-new-tokens-by-exchange) | exact, price calculated |
| `GET /token/:network/exchange/:exchange/bonding` | [Bonding tokens by exchange](/data-feeds/migration/solana-bonding-tokens-by-exchange) | progress exact, price calculated |
| `GET /token/:network/exchange/:exchange/graduated` | [Graduated tokens by exchange](/data-feeds/migration/solana-graduated-tokens-by-exchange) | exact (+ DEX pool) |
| `GET /token/:network/:address/bonding-status` | [Token bonding status](/data-feeds/migration/solana-token-bonding-status) | exact |

## Not covered yet

- **Other Solana endpoints** (prices, swaps, portfolio, metadata) are not yet covered.
- **Search and discovery endpoints** (`/tokens/search`, `/discovery/*`) are a search product, not an indexed feed.
- **RPC node methods** (`eth_*`) belong to the node product, not Data Feeds.
